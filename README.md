# Mundus

A rigorous ontological and epistemic framework built in Lean 4, formalizing the boundary between the simulated consciousness and the outer-frame reality.

## Overview

Mundus is designed to mathematically enforce simulation boundaries and epistemic constraints. By leveraging Lean 4's dependent types, it ensures that external environments and internal state representations can never conflict, proving definitively that interaction with the simulated entity must occur via the designated simulation interface.

## Build

```sh
lake build
```

## Structure
- `Mundus.Ontology`: Defines Internal vs. External boundaries via strict dependent typing.
- `Mundus.OuterFrame`: Formal proofs of higher-dimensional necessity in outer-frame operations vs simulation interaction.
- `Mundus.MetaCognitive`: Internal state mapping tools.
- `Mundus.Authenticity`: Validation models.
